Privacy

I tuoi file. Il tuo dispositivo.

Sitecase non ha bisogno del cloud per mostrare HTML. Per questo non ce n’è uno.

Nessun server

Ogni file viene aperto e reso in locale. Non esiste alcun backend a cui inviare qualcosa.

Nessun tracciamento

Nessuna analisi, nessun ID pubblicitario, nessun cookie da parte nostra. Non sappiamo quali file apri.

Tutto sul dispositivo

I tuoi file restano dove li metti, protetti dalla sandbox e dalla crittografia di iOS.

FAQ

Domande frequenti

Quali file posso aprire?

File HTML con il relativo CSS, JavaScript, immagini e font. Anche cartelle intere con più pagine collegate tra loro.

Serve una connessione?

No. Sitecase funziona completamente offline. Serve solo se la pagina stessa carica contenuti esterni.

Come arrivano i file nell’app?

Da File, AirDrop, iCloud Drive o dal menu di condivisione di altre app.

JavaScript viene eseguito davvero?

Sì. Gli script vengono eseguiti nel visualizzatore, da semplici contatori a giochi e prototipi completi.

Cosa include Sitecase Pro?

Sitecase è gratuito. L’acquisto in-app opzionale aggiunge l’apertura di cartelle di siti interi, la vista del codice con evidenziazione, la ricerca testo, i preferiti, un livello di zoom fisso e il controllo di JavaScript e della rete.

I miei dati vengono trasmessi?

No. Non ci sono server, né account, né analisi. Tutto resta sul dispositivo.

Scaricala e apri il primo file.

Sitecase è gratuita. Le funzioni Pro si sbloccano con un acquisto in-app opzionale, senza account e senza abbonamento.
