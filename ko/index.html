HTML 파일을 로컬에서 보기.

Sitecase는 기기에서 바로 HTML 파일을 열고, 렌더링하고, 검색합니다. JavaScript, CSS, 소스 보기를 지원합니다. 서버 없음, 계정 없음, 추적 없음.

기능 살펴보기
모든 데이터는 기기에 오프라인 작동 무료, Pro 선택

기능

어디서나 쓰는 완전한 HTML 뷰어.

웹 개발자, 학생, 교사, 그리고 이동 중에 HTML을 보고 싶은 모든 분을 위해. 단일 파일부터 프로젝트 전체까지.

JavaScript 실행

HTML, CSS, JavaScript를 완전하게 렌더링합니다. 계산기, 게임, 프로토타입이 네이티브로 실행됩니다.

폴더 통째로 열기 Pro

여러 파일로 구성된 프로젝트 전체를 엽니다. 이미지, CSS, JavaScript도 함께.

모던 CSS

Grid, Flexbox, 애니메이션, 웹 폰트를 픽셀 단위로 정확하게 표시합니다.

소스 보기 Pro

뷰어를 벗어나지 않고 구문 강조와 함께 모든 파일을 읽을 수 있습니다.

텍스트 검색 Pro

열린 파일 안에서 전체 텍스트를 검색하고 결과를 강조 표시합니다.

다크 모드

시스템 설정을 따르거나 고정할 수 있어 어떤 환경에도 어울립니다.

원하는 대로 확대

모든 페이지에서 핀치 확대, 그리고 고정 기본 확대 비율 Pro

즐겨찾기 Pro

자주 쓰는 파일과 폴더를 고정하고 한 번의 탭으로 다시 엽니다.

몇 초 만에 가져오기

파일 앱 또는 다른 앱의 공유 메뉴로.

네트워크 접근 제어

네트워크 접근을 언제든 켜거나 끌 수 있습니다. Pro에서는 JavaScript도 끌 수 있습니다.

단축어 및 Siri

저장한 파일을 바로 엽니다. 홈 화면 아이콘으로도 가능합니다.

완전 오프라인

연결 없이 사용 가능. 비행기에서도, 기차에서도, 신호가 없어도.

스크린샷

다른 사람들은 이렇게 씁니다.

문서, 단어 카드, 여행 계획, 프로토타입, 작은 게임. 모두 간단한 HTML 파일로.

추적 없음

분석 도구, 광고 ID, 자체 쿠키가 없습니다. 어떤 파일을 여는지 우리는 알지 못합니다.

FAQ

자주 묻는 질문

어떤 파일을 열 수 있나요?

HTML 파일과 관련 CSS, JavaScript, 이미지, 폰트입니다. 여러 페이지가 있는 폴더 전체도 열고 서로 연결할 수 있습니다.

인터넷 연결이 필요한가요?

아니요. Sitecase는 완전히 오프라인으로 렌더링합니다. 페이지 자체가 외부 콘텐츠를 불러올 때만 연결이 필요합니다.

파일은 어떻게 앱으로 가져오나요?

파일 앱 또는 다른 앱의 공유 메뉴를 이용합니다.

JavaScript가 정말 실행되나요?

네. 간단한 카운터부터 완전한 게임과 프로토타입까지 스크립트가 뷰어에서 실행됩니다.

Sitecase Pro에는 무엇이 포함되나요?

Sitecase는 무료로 사용할 수 있습니다. 선택형 앱 내 구입으로 여러 파일이 담긴 폴더 전체 열기, 구문 강조 소스 보기, 텍스트 검색, 즐겨찾기, 확대 비율 조정, JavaScript 끄기가 추가됩니다.

내 데이터가 전송되나요?

아니요. 서버도, 계정도, 분석도 없습니다. 모든 것이 기기에 남습니다.

지금 다운로드하고 첫 파일을 열어보세요.

Sitecase는 무료입니다. Pro 기능은 선택형 앱 내 구입으로 잠금 해제할 수 있으며, 계정도 구독도 필요 없습니다.
