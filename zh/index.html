隐私

常见问题

常见问题

可以打开哪些文件？

HTML 文件及其配套的 CSS、JavaScript、图片与字体。也可以打开包含多个页面的整个文件夹，并在页面之间跳转。

需要联网吗？

不需要。Sitecase 完全离线渲染。只有当页面本身加载外部内容时才需要网络。

如何把文件导入应用？

通过“文件”应用、AirDrop、iCloud 云盘或其他应用的共享菜单。

JavaScript 真的能运行吗？

可以。从简单的计数器到完整的游戏与原型，脚本都在阅读器中执行。

Sitecase Pro 包含什么？

Sitecase 免费使用。可选的应用内购买增加了打开整个网站文件夹、带高亮的源码查看、文本搜索、收藏、固定缩放级别，以及对 JavaScript 与网络访问的控制。

我的数据会被上传吗？

不会。没有服务器、没有账号、没有分析。一切都留在设备上。
